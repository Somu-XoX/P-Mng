# P-Mng 🔐

A Python-based GUI password manager built using Tkinter.

## Features
- Master password login
- Save credentials
- Retrieve passwords
- Password generator
- Auto copy to clipboard
- Dark/light mode toggle

## Tech Stack
- Python
- Tkinter
- JSON
- Pyperclip
- Hashlib

## Future Improvements
- Real encryption using cryptography
- Cloud storage
- Mobile/web version
